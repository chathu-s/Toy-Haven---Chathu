# Toy Haven

Toy Haven is a simple front-end e-commerce demo created for a university project. It shows a toy shopping experience with product browsing, search, cart management, wishlist handling, checkout simulation, and feedback forms.

## Features
- Product catalog with category filters
- Search box for quick product lookup
- Add-to-cart and quantity updates
- Wishlist tracking with status options
- Checkout simulation with validation
- Local storage persistence using browser storage
- Responsive design for mobile and desktop

## Tech Stack
- HTML
- CSS
- JavaScript

## How to run
1. Open the project folder in VS Code.
2. Start a simple local server in the project directory.
3. Open the browser and visit the local address.

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Presentation Flow
1. Open the Home page and explain the concept.
2. Show the Products page and category filters.
3. Add a few products to the cart.
4. Show the Wishlist and Checkout pages.
5. Explain that the project uses localStorage for demo data persistence.

## Main Files
- `index.html` – page structure and sections
- `styles.css` – layout and visual styling
- `script.js` – product data, cart logic, and interactions
- `sw.js` – service worker for PWA support

## Project Goal
This project demonstrates front-end e-commerce logic in a clean, presentation-friendly way for a university assignment.
